# 基础操作流程

## 界面布局

应用由三个区域组成：

1. **顶部导航栏** — 视图切换（月/周/日）、日期导航箭头、"今天"按钮、假期/回收站/新建任务按钮
2. **主视图区** — 月视图（7列网格）/ 周视图 / 日视图
3. **右侧边栏** — 月/周视图下显示选中日期的任务详情（宽 320px），日视图无侧边栏

## 创建任务

1. 点击右上角 **"+ 新建任务"** 按钮
2. 在弹出的对话框中填写：
   - **任务名称**（必填，未填提交时会有提示）
   - **任务类型**（日常/周期/复习/持续进度）
   - 类型相关字段（执行日期、重复频率、步骤等）
3. 点击"保存"

## 完成任务

- 点击任务卡片左侧的 **圆形按钮** 标记完成
- 已完成的任务会变为绿色，显示完成时间
- 再次点击可**撤销完成**

## 切换视图

顶部导航栏三个按钮：

- **月视图** — 7 列日历网格，每天用彩色圆点表示任务状态
- **周视图** — 7 天横向排列，每天显示任务名称标签
- **日视图** — 单日任务列表，使用卡片形式展示

## 日期导航

- 点击 **← →** 箭头切换月份/周/日
- 点击 **"今天"** 按钮跳回当前日期
- 月/周视图下点击某一天 → 右侧边栏显示该日任务

## 假期模式

- 点击顶部 **日历图标按钮** 打开假期对话框
- 添假期区间（起始日期 + 结束日期）
- 开启开关 → 假期区间内周期任务和持续进度任务自动隐藏
- 日常任务和复习任务不受影响
- 关闭开关 → 恢复显示，任务数据不受影响

## 回收站

- 删除的任务会进入回收站（保留到次日 24 点）
- 点击顶部 **垃圾桶图标** 打开回收站
- 可恢复或彻底删除

## 任务视图（聚焦模式）

- 点击任务卡片上的 **"在日历上查看"** 按钮
- 月/周视图中仅高亮该任务的日期，其他内容半透明
- 点击顶部 **"退出任务视图"** 或再次点击同一任务按钮退出
