# 高级功能

## 四种任务类型详解

### 日常任务 (SingleTask)

适用于一次性、当天执行的任务。

- **执行日期** — 指定唯一执行日
- **计数模式**（可选）— 开启后同一天可多次完成并记录次数（如"喝水 3/8"）

### 周期任务 (RecurringTask)

适用于每天/每周/每月或按自定义间隔重复的任务。

- **开始日期** — 首次出现的日期
- **重复频率** — 每天 / 每周 / 每月 / 自定义天数（每 N 天）
- **结束条件** — 永不结束 / 完成 N 次后停止 / 指定截止日期
- **暂停** — 可随时暂停，暂停后不再生成新的实例
- **计数模式**（可选）— 每个发生日可多次完成

### 复习任务 (EbbinghausTask)

适用于艾宾浩斯间隔复习，如背单词、学习卡片。

- **开始日期** — 第 0 天（首次学习日）
- **间隔序列** — 默认 `0, 1, 2, 4, 7, 15, 30, 60`，可自定义
  - 例如：第 0 天学习 → 第 0 天复习 → 第 1 天复习 → 第 3 天复习...
- **结束条件** — 永不结束 / 完成 N 轮复习后停止
- **间隔预览表** — 创建时可查看未来复习日期
- **学习主题** — 可关联学习主题进行分类（需先在数据层创建主题）

### 持续进度任务 (ProgressTask)

适用于有累积进度的任务，如阅读、课程、项目推进。

- **开始日期** — 进度起点
- **步骤列表** — 每个步骤有独立的推进天数（`interval`）
  - 步骤按顺序循环：完成步骤A → 进度条推进 interval 天 → 进入步骤B
  - 例如：步骤A(3天) → 步骤B(7天) → 回到步骤A(3天)...
- **起始步骤索引** — 可从任意步骤开始（创建后不可修改）
- **同日多次完成** — 支持每天多次完成（链式推进），每次按当前步骤的 interval 推进进度条
- **进度条** — 绿色区域表示已被进度覆盖的日期；`barEnd` 后到今天为红色逾期区域

## 任务视图（聚焦模式）

聚焦模式下，进度任务有特殊染色：

- 从 `startDate` 到 `barEnd`（进度条终点）→ **绿色**
- `barEnd` 之后到今天 → **红色**（逾期未覆盖）
- 今天之后 → 无特殊染色

## 步骤管理

在创建/编辑持续进度任务时：

1. 点击"添加步骤"增加步骤行
2. 填写**步骤名称**和**推进天数**
3. 步骤按列表顺序循环执行
4. 已有完成记录的任务其**步骤结构被锁定**（不可新增、删除、重排步骤，不可切换简洁/详细模式，不可修改起始步骤索引），但步骤名称、推进天数与起始日期仍可修改；推进天数与起始日期的修改会基于当前设置实时重算进度条覆盖范围

## 数据备份

数据存储在浏览器 `localStorage`（键名 `calendar-app-state`）。

### 导出数据

```js
copy(localStorage.getItem('calendar-app-state'))
```

### 导入数据

```js
localStorage.setItem('calendar-app-state', '<粘贴的JSON字符串>')
location.reload()
```

### 清空数据

```js
localStorage.removeItem('calendar-app-state')
location.reload()
```

## 分组与主题

- **任务分组** — 数据层已支持（`TaskGroup`），删除分组时级联删除同组任务，恢复时级联恢复。当前 UI **暂无创建分组的入口**
- **学习主题** — 创建复习任务时可选择/创建学习主题，用于分类管理
