# 安全策略

> ⚠️ **占位文件 — 当前仅记录现状**

「日程安排」为纯客户端应用，安全面较简单：

## 当前安全现状

- **无后端** — 无网络请求，无 API 端点暴露
- **无密钥凭证** — 代码中不含任何硬编码密钥、Token 或密码
- **数据隔离** — 所有数据仅存于用户本地浏览器 `localStorage`，不发送到任何服务器
- **无第三方依赖的数据共享** — `@vercel/analytics` 仅收集匿名页面浏览统计

## 注意事项

- `scripts/serve.mjs` 会执行 `kill -9` 释放端口，仅限本地开发使用
- `localStorage` 数据可被同源脚本读取，注意浏览器扩展和 XSS 风险
- 依赖安装使用 pnpm，新增依赖前确认项目是否已有同类库
