# 日历视图规格

本文档描述三种日历视图的渲染逻辑和组件结构。

## 视图切换

顶部导航栏三个按钮：月 / 周 / 日。由 `CalendarHeader` 组件管理，`CalendarApp` 的 `view` 状态控制。

---

## 月视图 (MonthView)

### 布局

7 列 × 6 行网格（由 `getMonthGrid()` 生成），周日起始。每个日期格显示：
- 日期数字
- `DotsRow` — 彩色小圆点行，按任务类型和状态分配颜色

### 圆点颜色规则

| 状态 | 颜色 |
|------|------|
| `completed` | 绿色 |
| `missed` | 红色 |
| `holiday` | 灰色 |
| `skipped` | 黄色 |
| `pending` / `future` | 任务类型色 |

### 交互

- 点击某一天 → 右侧边栏显示该日任务详情
- 当天格有特殊样式标记

---

## 周视图 (WeekView)

### 布局

7 天横向排列（周日到周六），每天一列。显示：
- 日期信息（星期几 + 日期数字）
- 按任务名分组的实例标签

### 交互

- 点击某一天 → 右侧边栏显示该日任务详情

---

## 日视图 (DayView)

### 布局

全宽单日任务列表。每个实例使用 `InstanceItem` 卡片渲染。

### InstanceItem 卡片

每张卡片显示：
- 完成/撤销按钮（计数模式显示 "N/M" 次数）
- 任务名 + 类型标签
- 状态标签（已错过、已完成等）
- 附加信息（meta，如"第 3 次复习"）
- 操作按钮：暂停切换、在日历上查看

---

## 右侧边栏 (DaySidebar)

- 宽度 320px
- 月/周视图下显示选中日期的任务
- 日视图下不显示（任务已在主区域展示）
- 选中日期的实例单独按单日范围计算，保证三视图一致

---

## 任务视图（聚焦模式）

点击"在日历上查看"后激活，`focusedTaskId` 非空：

### 非进度任务
- 月/周视图中仅高亮该任务出现的日期
- 其他日期半透明隐藏

### 进度任务
- `startDate` → `barEnd`：绿色进度条覆盖
- `barEnd` 之后 → 今天：红色逾期区域
- 今天之后：无特殊染色
- paused 任务进度条截至今天

### 退出
- 点击"退出任务视图"按钮
- 再次点击同一任务的"在日历上查看"
- 删除聚焦任务或其同组任务时自动退出

---

## 底部提醒条

由 `countTodayMissed()` 统计错过实例数（**排除进度任务**），在底部显示红色提醒。
